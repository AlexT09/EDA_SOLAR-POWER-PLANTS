1. Carga y estructura del dataset#

El dataset Dataset_Mundial_Final.csv reúne 58 978 plantas solares fotovoltaicas de todo el mundo, descritas por 29 columnas de terreno, clima, logística y potencia. El archivo usa ; como separador y coma decimal; la función load_data() del módulo utils.py lo carga y convierte la clase objetivo en una categoría ordenada Baja < Media < Alta.

import warnings

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from utils import *

pd.set_option("display.max_columns", 40)

1.2 Rol de cada variable en el modelado#

Se mantiene la definición de la segunda entrega: la variable objetivo es solar_aptittude_class y se usan 17 predictoras (13 numéricas y 4 categóricas). Las demás columnas se excluyen por fuga de datos, por ser posteriores a la decisión de inversión o por ser identificadores; el capítulo 8 justifica cada exclusión.
